# 8장. 두 비주얼 테마의 디자인 가이드

[← 목차로](README.md)

> **v0.2:** 2D 도트 테마를 **기본 시안**으로 정하고 HTML 시제품으로 먼저 구현했다([8.4](#84-도트-테마-html-시제품-v02)). 모던 미니멀 테마는 설정에서 고르는 대체 테마로 유지한다.

## 8.0 공통 원칙 — "하나의 로직, 두 개의 옷"

| 항목 | 공유 (테마와 무관) | 테마별로 교체 |
|---|---|---|
| 게임 규칙·사례 데이터·판정 로직·점수·저장 | ✔ | — |
| 화면 구조(UXML 레이아웃), 화면 흐름, 터치 영역 크기 | ✔ | — |
| 색상 토큰 값, 글꼴, 테두리·패널 이미지, 아이콘 세트 | — | ✔ |
| 효과음 세트, 화면 전환·피드백 애니메이션 프로필 | — | ✔ |
| 센터 배경 일러스트, 캐릭터(도트·센터장) 그림 | — | ✔ |

- 두 테마는 **같은 디자인 토큰 이름**을 쓰고 값만 다르다(예: `--color-surface`, `--color-approve`, `--radius-card`, `--space-m`). 구현 방식은 [9장 ThemeManager](06-unity-architecture.md#913-thememanager) 참고.
- **색상만으로 의미를 전달하지 않는다.** 판정·상태는 항상 *아이콘 + 텍스트 + (선택적으로) 패턴*을 함께 쓴다.

### 의미 표현 공통 규칙

| 의미 | 아이콘 | 텍스트 | 모던(A) 색 | 도트(B) 색 | 추가 구분 |
|---|---|---|---|---|---|
| 승인 | ✔ (체크) | "승인" | 청록 | 픽셀 초록 | 버튼 위치: 왼쪽 |
| 거부 | ✖ (엑스) | "거부" | 코랄 레드 | 픽셀 빨강 | 버튼 위치: 가운데 |
| 추가 확인 | ? + 돋보기 | "추가 확인" | 앰버 | 픽셀 노랑 | 버튼 위치: 오른쪽, 테두리 점선 |
| 일치 | ✓ | "일치" | 청록 | 초록 | — |
| 불일치 | ⚠ | "불일치" | 앰버 | 노랑 | 빗금 패턴 배경 |
| 의심 표시 | 🚩 | "의심" | 코랄 | 빨강 | 깃발 아이콘 |
| 위험 요소(해설) | ❗ | "위험 요소" | 코랄 | 빨강 | 굵은 점선 테두리 |

> 판정 버튼 3개의 순서(승인·거부·추가 확인)는 모든 사례와 두 테마에서 고정한다. 선택지가 2개인 사례에서는 해당 버튼만 표시하되 **순서는 유지**한다.

## 8.1 버전 A — 모던 미니멀 UI

### 콘셉트
> "차분한 보안 대시보드." 깔끔한 카드, 넉넉한 여백, 명확한 정보 위계.

### 색상 토큰

| 토큰 | 용도 | 값 | 대비 기준(텍스트 사용 시) |
|---|---|---|---|
| `--color-bg` | 화면 배경 | `#F4F6FA` | — |
| `--color-surface` | 카드·문서 배경 | `#FFFFFF` | — |
| `--color-primary` | 상단 바, 강조 제목 | 네이비 `#14284B` | 흰 글자 대비 14.6:1 |
| `--color-primary-deep` | 다크 영역 | `#0B1A33` | — |
| `--color-accent` | 선택, 포커스, 링크 | 청록 `#0E7C7B` | 흰 글자 대비 5.0:1 (AA 통과) |
| `--color-approve` | 승인 버튼 | `#0E7C7B` | 흰 글자 |
| `--color-reject` | 거부 버튼 | 코랄 레드 `#C23B33` | 흰 글자 대비 5.3:1 |
| `--color-verify` | 추가 확인 버튼 | 앰버 `#E3A622` | **검은 글자**(`#1A1A1A`) 사용, 대비 8.1:1 |
| `--color-text` | 본문 | `#1C2433` | 배경 대비 14.4:1 |
| `--color-text-sub` | 보조 텍스트 | `#556070` | 배경 대비 5.9:1 (카드 위 6.4:1) |
| `--color-highlight` | 형광 강조(대조 중 필드) | `#FFF3B0` | — |

> 대비 수치는 위 색상값으로 WCAG 상대 휘도 공식에 따라 계산한 값이며, 최종 색상은 제작 단계에서 대비 측정 도구로 WCAG 2.1 AA(본문 4.5:1, 큰 글자 3:1) 충족을 확인한다.

**다크 모드(P2)**: 같은 토큰 이름에 `bg #0B1A33 / surface #14284B / text #EEF2F8 / accent #3CC4C2` 등 별도 값 세트를 둔다.

### 타이포그래피

| 역할 | 글꼴 | 크기 (100% 기준, 1080×1920 기준 px / 대략 dp) | 굵기 |
|---|---|---|---|
| 화면 제목 | Pretendard (SIL OFL) | 60px / 22dp | Bold |
| 카드 제목 | Pretendard | 48px / 18dp | SemiBold |
| 문서 필드 라벨 | Pretendard | 38px / 14dp | Medium, 보조색 |
| 문서 필드 값 | Pretendard | 44px / 16dp | Regular |
| 버튼 | Pretendard | 46px / 17dp | Bold |
| 이메일·URL·ID | 고정폭 글꼴(예: D2Coding, SIL OFL) | 42px / 15dp | Regular |

- 이메일·URL·계정 ID는 **고정폭 글꼴**로 표시해 `l`/`1`, `O`/`0`, `rn`/`m` 같은 비슷한 글자를 구분하기 쉽게 한다. (사칭 도메인 판별 학습에 중요)
- 줄 간격 150%, 한 줄 최대 22자 내외(한글 기준)에서 줄바꿈되도록 카드 폭을 설계한다.

### 레이아웃·형태

| 항목 | 값 |
|---|---|
| 기본 간격 단위 | 8dp 그리드 (`--space-xs 4 / s 8 / m 16 / l 24 / xl 32`) |
| 카드 모서리 | 16dp 둥글기, 그림자 1단계(y 2dp, blur 8dp, 10% 불투명) |
| 문서 카드 | 흰 카드 + 상단 4dp 컬러 띠(문서 종류별: 메일=네이비, 공유=청록, 알림=보라 `#5B4BC4`) + 문서 아이콘 + 종류 텍스트 |
| 필드 | 라벨(위) / 값(아래) 2줄 구조. 필드 간 구분선 1dp `#E3E7EE` |
| 버튼 | 높이 56~64dp, 모서리 12dp, 아이콘 24dp + 텍스트 |
| 바텀 시트 | 상단 모서리 24dp, 손잡이 바 표시 |

### 아이콘·일러스트
- 선 굵기 2dp의 라운드 라인 아이콘. 채움 아이콘은 '선택됨' 상태에만 사용.
- 센터 배경: 플랫 일러스트(밝은 사무 공간, 창밖 누리시 풍경). 캐릭터 도트는 둥근 모니터 얼굴의 작은 로봇, 표정 6종(기본·웃음·생각·놀람·응원·잠).

### 모션

| 상황 | 연출 | 길이 |
|---|---|---|
| 요청 카드 도착 | 위에서 아래로 슬라이드 + 페이드 | 250ms, ease-out |
| 단서 칩 생성 | 대조한 두 필드 사이에서 칩이 튀어나와 근거 트레이로 이동 | 400ms |
| 정답 | 체크 아이콘 원형 그리기 + 짧은 맑은 효과음 + 가벼운 진동(10ms) | 500ms |
| 오답 | 카드가 살짝 기울었다 돌아옴(흔들림 아님) + 부드러운 효과음, **진동 없음** | 300ms |
| 움직임 줄이기 ON | 모든 이동·확대 연출을 페이드(150ms) 또는 즉시 표시로 대체 | — |

## 8.2 버전 B — 2D 도트 스타일

### 콘셉트
> "레트로 보안 관제실." 둥근 CRT 모니터, 깜빡이는 상태 램프, 픽셀 서류철. 단, **문서 글자는 언제나 선명하게**.

### 픽셀 그리드와 렌더링 규칙

| 항목 | 규칙 |
|---|---|
| 아트 기준 해상도 | 360×640 논리 픽셀로 그리고 **정수 배율(×3 → 1080×1920)**로 확대 |
| 비정수 해상도 기기 | 가장 가까운 정수 배율로 렌더링하고 남는 영역은 테마 배경 패턴으로 채움(레터박스). 문서 텍스트 영역은 화면 폭에 맞춰 리플로우 |
| 텍스처 | Point(필터 없음) 샘플링, 압축 없음 또는 무손실, 밉맵 끔 |
| Pixel Perfect | 배경·장식 스프라이트는 Pixel Perfect Camera(2D) 사용. UI 텍스트는 별도 캔버스/패널에서 정수 크기로 렌더 |
| 9-slice | 모든 패널·버튼 테두리는 9-slice 스프라이트로 늘려도 픽셀이 뭉개지지 않게 |

### 제한 팔레트 (16색, 자체 제작)

| # | 이름 | 값 | 주 용도 |
|---|---|---|---|
| 0 | 밤하늘 | `#0F1426` | 가장 어두운 배경 |
| 1 | 관제실 남색 | `#1F2A4A` | 패널 배경 |
| 2 | 스틸 블루 | `#3A4E7A` | 패널 테두리 |
| 3 | 흐린 하늘 | `#7F9CC9` | 비활성, 보조선 |
| 4 | 종이 | `#F2EBD9` | **문서 배경** |
| 5 | 잉크 | `#22201F` | **문서 글자** |
| 6 | 연필 회색 | `#6B6560` | 문서 라벨 |
| 7 | 형광 노랑 | `#F7D84A` | 대조 강조, 추가 확인 |
| 8 | 램프 초록 | `#3FBF6F` | 승인, 일치 |
| 9 | 깊은 초록 | `#23784A` | 승인 버튼 그림자 |
| 10 | 경고 빨강 | `#E0503C` | 거부, 의심 |
| 11 | 깊은 빨강 | `#8E2B25` | 거부 버튼 그림자 |
| 12 | 화면 청록 | `#45C7C1` | CRT 화면 글자, 선택 |
| 13 | 보라 램프 | `#8A6BD1` | 알림 문서 |
| 14 | 나무 갈색 | `#8A5A3B` | 책상, 서류철 |
| 15 | 흰 빛 | `#FFFFFF` | 하이라이트 점 |

- 문서 본문은 **종이(#4) 위 잉크(#5)** 조합(대비 13.6:1)만 사용해 최고 대비를 유지한다. 라벨용 연필 회색(#6)은 종이 위 4.8:1로 AA를 충족한다.
- 고대비 모드에서는 문서 배경을 `#FFFFFF`, 글자를 `#000000`으로 바꾼다.

### 픽셀 글꼴

| 역할 | 글꼴(후보) | 렌더 크기 |
|---|---|---|
| 제목·버튼·UI 라벨 | 갈무리(Galmuri) 14 계열 (SIL OFL, 한글 픽셀 글꼴) | 원본 크기의 정수배 |
| 문서 본문 | 갈무리 11 계열 | 원본 크기의 정수배, **최소 표시 높이 약 15dp** |
| 이메일·URL | 갈무리 Mono 계열 | 정수배 |
| 대체(가독성 모드) | Pretendard / D2Coding | 모던 테마와 동일 |

- 글꼴 라이선스(SIL OFL)는 설정 > 정보 > 오픈소스 라이선스에 고지한다. 최종 채택 전 글리프 범위(KS X 1001 완성형 2,350자 외 필요 글자 포함 여부)를 검증한다.
- **가독성 우선 옵션**: 설정의 "문서 본문 글꼴: 일반 글꼴"을 켜면, 도트 테마에서도 *문서 본문만* 일반 글꼴로 표시하고 나머지 UI는 픽셀 스타일을 유지한다. 글자 크기 150%에서는 이 옵션을 권장하는 안내를 띄운다.

### 화면 요소 변환표 (A ↔ B)

| 공통 요소 | 모던(A) | 도트(B) |
|---|---|---|
| 상단 바 | 네이비 바 + 흰 텍스트 | 금속 패널 + 빨강/초록 상태 램프 픽셀 |
| 요청 카드 | 흰 카드 + 그림자 | 기송관(파이프)에서 떨어지는 서류 봉투 |
| 문서 뷰어 | 흰 카드 | 크림색 종이 서류, 클립 장식 |
| 문서 트레이 | 탭 칩 | 책상 위 서류철 탭(색 띠 + 아이콘 + 글자) |
| 도구 바 | 라인 아이콘 + 라벨 | 픽셀 도구(돋보기·깃발·책·전화기) + 라벨 |
| 단서 칩 | 둥근 칩 | 작은 포스트잇 픽셀 |
| 판정 버튼 | 플랫 버튼 | 두툼한 아케이드 버튼(눌림 1px 하강 애니메이션) |
| 정답 연출 | 체크 원 그리기 | 초록 램프 점등 + 8bit 효과음 + '승인' 도장 쾅(2프레임) |
| 오답 연출 | 카드 살짝 기울기 | 모니터에 '?' 픽셀 아이콘이 떠오름(빨간 경고 화면 사용 안 함) |
| 도트(AI 조수) | 플랫 일러스트 | 32×32 픽셀 로봇, 4프레임 대기 애니메이션 |

### 애니메이션 규칙
- 프레임 애니메이션 기본 8~12fps. 상태 램프 깜빡임은 1초 주기 이하로 느리게(광과민성 고려, 초당 3회 이상 깜빡임 금지).
- 움직임 줄이기 ON 시 대기 애니메이션 정지, 도장·램프 연출은 정지 이미지로 대체.

## 8.3 두 테마 공통 품질 기준

| 기준 | 확인 방법 |
|---|---|
| 같은 사례를 두 테마로 플레이했을 때 표시 정보가 완전히 같다 | 사례별 스크린샷 비교 테스트 ([14장](09-roadmap-and-tests.md)) |
| 최소 지원 해상도(360×640dp)·글자 크기 150%에서 문서 텍스트가 잘리지 않는다 | 디바이스 매트릭스 테스트 |
| 판정 버튼은 색을 흑백으로 바꿔도 구분된다 | 흑백 필터 스크린샷 검사 |
| 테마 전환 시 진행 상태(현재 사례·단서·깃발)가 유지된다 | 플레이 중 설정에서 테마 전환 테스트 |

## 8.4 도트 테마 HTML 시제품 (v0.2)

| 항목 | 내용 |
|---|---|
