## 한 문단 요약

플레이어는 가상 도시 **누리시**의 **누리 디지털 안전 센터**에서 일하는 *청소년 보안 심사관*입니다. 매일 아침 그날의 보안 규칙을 확인하고, 학교 학습 플랫폼·디지털 도서관·게임 서비스·클라우드 드라이브에서 들어오는 **파일 공유 요청, 로그인 알림, 권한 요청, 의심 메시지**를 검토합니다. 서로 다른 문서의 정보를 **돋보기로 대조해 단서를 모으고**, 위험한 부분에 **깃발을 꽂은 뒤**, 요청을 **승인 · 거부 · 추가 확인**으로 판정합니다. 위험을 잡아내는 것만큼 **정상 요청을 막지 않는 것**도 중요하게 평가하므로, 플레이어는 "무조건 거부"가 아니라 *근거 있는 판단*을 연습하게 됩니다. 틀려도 힌트를 받고 다시 생각할 수 있으며, 모든 사례는 해설과 복습 노트로 남습니다.

## 설계 원칙 요약

1. **근거 있는 판단 > 빠른 판단** — 시간 제한은 기본 꺼짐. 정확도와 근거 확인을 가장 크게 보상한다.
2. **안전과 편의의 균형** — 불필요한 거부(과잉 차단)도 실수로 기록한다.
3. **겁주지 않는 교육** — 공포가 아닌 *예방과 대응 방법*을 알려 준다. 오답 메시지는 다정하게.
4. **규칙 먼저, 적용은 나중** — 새 규칙은 항상 설명·예시·연습 → 실전 순서로 도입한다.
5. **데이터 중심 설계** — 사례·규칙은 ScriptableObject 데이터. 정답은 규칙 판정기로 자동 검증해 데이터와 정답의 모순을 막는다.
6. **하나의 로직, 두 개의 옷** — 모던 미니멀 테마(A)와 2D 도트 테마(B)는 같은 로직·데이터를 공유하고 테마 자산만 교체한다.
7. **아동 보호 우선** — 실제 개인정보 입력 없음, 실존 기관·인물 사칭 없음, 광고·결제·추적 없음, 오프라인 플레이.
