## 한 문단 요약

플레이어는 가상 도시 **누리시**의 **누리 디지털 안전 센터**에 새로 들어온 *디지털 안전 심사관*입니다. 매일 아침 그날의 보안 규칙(오늘의 조건)을 확인하고, 학교·도서관·게임·택배·쇼핑·가족 메신저에서 들어오는 **문자, 메일, 첨부 파일, 파일 공유 요청, 로그인 알림, 권한 요청**을 검토합니다. 메시지가 *주장하는 것*과 요청자가 *원래 알던 것*(내 기록)을 나란히 놓고 봅니다. 서로 다른 문서의 정보를 **돋보기로 대조해 단서를 모으고**, 위험한 부분에 **깃발을 꽂은 뒤**, 요청을 **승인 · 거부 · 추가 확인**으로 판정하고, 거부한 경우에는 신고할지도 정합니다. 위험을 잡아내는 것만큼 **정상 요청을 막지 않는 것**도 중요하게 평가하므로, 플레이어는 "무조건 거부"가 아니라 *근거 있는 판단*을 연습하게 됩니다. 실패해도 모든 사건의 정답과 해설을 보여 주며, 틀린 사건은 복습 노트로 남습니다.

## 설계 원칙 요약

1. **근거 있는 판단 > 빠른 판단** — 시간 제한은 기본 꺼짐. 판정마다 정답을 알려 주지 않아 규칙과 자료에 기대어 판단하게 하고, 정확도와 근거 확인을 가장 크게 보상한다.
2. **안전과 편의의 균형** — 불필요한 거부(과잉 차단)도 실수로 기록한다.
3. **겁주지 않는 교육** — 공포가 아닌 *예방과 대응 방법*을 알려 준다. 실패해도 탓하지 않고 모든 정답·해설을 보여 준다.
4. **규칙 먼저, 적용은 나중** — 새 규칙은 항상 설명·예시·연습 → 실전 순서로 도입한다.
5. **데이터 중심 설계** — 사례·규칙은 ScriptableObject 데이터. 정답은 규칙 판정기로 자동 검증해 데이터와 정답의 모순을 막는다.
6. **하나의 로직, 두 개의 옷** — 2D 도트 테마(기본 시안)와 모던 미니멀 테마는 같은 로직·데이터를 공유하고 테마 자산만 교체한다.
7. **모든 세대를 위한 보호** — 전연령이어도 아동 보호 기준을 그대로 적용한다. 실제 개인정보·나이 입력 없음, 실존 기관·인물 사칭 없음, 광고·결제·추적 없음, 오프라인 플레이.
8. **정답을 흘리지 않는다** — 문서 안에 판정을 대신해 주는 문장을 넣지 않는다. 위험하지 않은 낯선 파일·기기도 섞어 낸다.

## v0.3 주요 변경

- 판정 확인 단계("정말 ○○할까요?") 제거 — 승인은 즉시, 거부·추가 확인은 신고·경로를 받는 처리 시트만
- 남은·전체 사건 수 표시 제거
- 판정 직후 정답 비공개 → 근무 결과에서 사건별 정답·해설 공개 (오답 힌트·다시 생각하기 삭제)
- 실패 규칙: 위험도 높음 사건 승인 = 보안 사고(즉시 종료), 처리 성공률 60% 미만 = 점검 미달 → 결과를 보고 그 Day를 처음부터 다시
- 표지·첫 화면의 디지털 보안관을 도트 캐릭터로 교체, 발표 자료를 도트 스타일로 재제작
- 자세한 내용: [3.4 v0.3 판정 흐름 변경](01-overview.md#34-v03-판정-흐름-변경)
