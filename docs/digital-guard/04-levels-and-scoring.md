### 6.3 난이도 조절 변수

난이도는 문서 양이 아니라 **판단에 필요한 정보와 규칙의 복잡도**로 조절한다. 각 사례 데이터에는 아래 변수를 기록하고, 콘텐츠 제작 시 등급별 범위를 지킨다.

| 변수 | 설명 | 초급 | 중급 | 고급 | 심화 |
|---|---|---|---|---|---|
| 적용 규칙 수 | 정답 판단에 필요한 규칙 개수 | 1 | 1~2 | 2~3 | 2~4 |
| 대조 단계 | 정답을 위해 필요한 최소 대조 횟수 | 1 | 2~3 | 3~4 | 3~5 |
| 단서의 명시성 | 직접 보이는가, 추론해야 하는가 | 직접 (이름이 다름) | 반직접 (도메인 끝부분 읽기) | 추론 (목적 대비 불필요) | 추론 + 정보 부재 인식 |
| 함정(방해 요소) | 그럴듯하지만 판정과 무관한 정보 | 0 | 0~1 | 1~2 | 1~2 |
| 정상/위험 유사도 | 정상 사례와 위험 사례가 얼마나 비슷한가 | 낮음 | 중간 (짝 사례) | 높음 | 높음 |
| 판정 단계 | 한 사례의 판정 횟수 | 1 | 1 | 1 | 1~2 |
| 근거 선택 | 판정 근거를 고르는가 | 없음 | 없음 | 있음 | 있음 |
| 관련 규칙 표시(📌) | 규칙집이 관련 규칙을 알려 주는가 | 표시 | 표시 | 없음 | 없음 |
| 문서 수 | 사례에 포함된 문서 | 2 | 2~3 | 2~4 | 3~5 |

> 예: C1-01과 C3-02는 둘 다 '파일 공유' 사례지만, C1-01은 이름 1종류만 대조하면 되고(초급), C3-02는 공개 범위·파일 내용·요청 목적을 함께 판단하고 '보기만 가능'이라는 함정을 넘어야 한다(고급).

## 7. 점수 및 진행 시스템

### 7.1 평가 철학

1. **정확성 > 속도** — 시간 점수는 *선택 모드*에서만, 그리고 보너스로만 존재한다. 느리다고 감점하지 않는다.
2. **양방향 실수 모두 기록** — 위험한 요청을 통과시키는 것(위험 승인)과 정상 요청을 막는 것(과잉 차단)을 따로 측정한다.
3. **근거를 보상** — 맞힌 판정이라도 근거를 확인했는지 별도로 평가한다(찍기 방지).
4. **실패해도 전진** — 하루를 끝까지 하면 항상 다음 Day가 열린다. 점수는 '얼마나 잘했나'를 보여 주는 거울이지 관문이 아니다.

### 7.2 사례 1건 점수 계산

| 구성 요소 | 조건 | 점수 |
|---|---|---|
| **판정 점수** | 첫 시도 정답 | 100 |
| | 재시도(힌트 후) 정답 | 60 |
| | 허용 대안 선택 | 100 × 대안 배율 (예: C4-01 거부 = 50, C4-02-S1 거부 = 70) |
| | 2회 오답 / 정답 보기 선택 | 0 (감점 없음) |
| **위험 탐지** | 필수 위험 위치에 깃발 (1곳당) | +20 |
| | 선택 위험 위치에 깃발 (1곳당) | +10 |
| | 위험이 아닌 필드에 깃발 (1곳당) | −5 (위험 탐지 점수 하한 0, 다른 점수는 깎지 않음) |
| **근거 확인** | 핵심 근거 필드(`keyEvidence`) 쌍을 모두 대조함 | +20 |
| **근거 선택** (고급 이상) | 정답 근거 전부 선택 + 오답 근거 0개 | +30 |
| | 정답 근거 일부 선택 + 오답 근거 0개 | +15 |
| | 오답 근거 포함 | 0 |
| **확인 경로** (추가 확인 정답 시) | 첫 번째 선택에서 공식 경로 | +30 |
| | 두 번째 선택에서 공식 경로 / 두 번 다 틀림 | 0 (판정 점수는 유지, 올바른 경로를 보여 주고 진행) |
| **신고 판단** (거부 정답 시) | 신고 시트의 선택이 정답(`reportable`)과 같음 | +10 (틀려도 감점 없음) |
| **연속 정답 보너스** | 첫 시도 정답이 연속될 때, 2연속부터 | +10 × (연속 수 − 1), 최대 +40 |
| **시간 보너스** (시간 도전 모드에서만) | 기준 시간(`parTimeSeconds`) 안에 첫 시도 정답 | +20 |

- 재시도 정답·허용 대안은 연속 정답을 *끊지 않고 유지*만 한다(증가 없음). 2회 오답이나 '정답 보기'일 때만 연속이 0으로 돌아간다. → 실수 한 번에 크게 낙담하지 않도록.
- 판정은 맞고 근거만 틀린 경우 재도전은 없고 근거 점수만 0이다. 연속 정답은 이어진다.
- 승인이 정답인 사례에서는 위험 위치가 없으므로, 깃발을 꽂지 않으면 위험 탐지 항목은 "해당 없음"으로 처리한다(만점 기준에서 제외).

**계산 예시 — C2-01 (가짜 계정 정지 메일)**
첫 시도 거부 정답 100 + 필수 위험 위치 2곳(보낸 사람, 링크) 깃발 40 + 선택 위치(비밀번호 요구) 10 + 핵심 근거 대조 20 + 신고하기 10 + 연속 3번째 정답 20 = **200점**

**계산 예시 — C4-01을 '거부'로 판정**
허용 대안 50 + 필수 위험 위치(승인자 칸) 20 + 근거 대조 20 = **90점** (확인 경로 점수는 추가 확인을 골랐을 때만 해당), 연속 정답 유지(증가 없음)

| ★★ | 판정 정확도 70% 이상 |
| ★★★ | 판정 정확도 90% 이상 **그리고** 위험 탐지율 80% 이상 **그리고** 위험도 '높음' 사례의 위험 승인 0건 |

- 별은 Day별 최고 기록만 저장한다. 별 누적 수로 센터 꾸미기 아이템과 칭호가 열린다(예: 별 10개 = 화분, 30개 = 레트로 모니터, 50개 = '침착한 심사관' 칭호).

### 7.5 학습 진행도 (주제별 숙달도)

10개 교육 주제(E1~E11 중 E3·E8을 '로그인과 인증'으로 묶어 10개) 각각에 숙달도를 둔다.

| 단계 | 아이콘·라벨 | 조건 |
|---|---|---|
| 0 | 🔒 잠김 | 규칙 미도입 |
| 1 | 🌱 배움 | 해당 규칙의 아침 브리핑 완료 |
| 2 | 🌿 연습 | 해당 주제 사례 3건 이상 판정 |
| 3 | 🌳 숙달 | 해당 주제의 *최근 8건* 중 첫 시도 정답 6건 이상(75%) **그리고** 서로 다른 Day의 사례 2개 이상 포함 |

- 숙달 판정은 *최근 기록*을 쓰므로, 처음에 많이 틀려도 복습·연습실에서 다시 올릴 수 있다.
- 숙달도는 하락 표시를 하지 않는다(🌳에서 🌿로 내려가지 않음). 다만 최근 정답률이 60% 미만이면 카드에 "복습하면 좋아요" 배지를 띄운다.

### 7.8 플레이 모드 (전연령 지원)

나이를 묻지 않고, 플레이어가 자기에게 맞는 모드를 고른다. 모드는 **판단에 필요한 정보와 정답은 바꾸지 않고**, 도움의 양과 화면 정보량만 바꾼다. 따라서 모든 모드에서 같은 사례 데이터와 판정 로직을 쓴다.

| 항목 | 차근차근 | 표준 (기본) | 도전 |
|---|---|---|---|
| 오늘의 조건 띠 | 두 줄로 크게, 처음 사례 전 자동으로 한 번 펼침 | 한 줄 | 한 줄 |
| 관련 규칙 표시(📌) | 모든 Day에서 표시 | Day 1~9만 표시 ([S06](02-screens.md#s06-규칙집-시트)) | 표시 안 함 |
| 힌트 | 1차 오답 힌트 + "어디를 보면 될까요?" 버튼(정답 직전까지 볼 곳을 한 군데 짚어 줌) | 1차 오답 힌트 | 1차 오답 힌트 |
| 대조 결과 표시 | 즉시 표시 | 즉시 표시 | 끌 수 있음(일치/불일치를 스스로 판단) |
| 한 Day 사례 수 | 4~5건(짝 사례 우선) | 6~7건 | 6~7건 + 도전 사례 1건 |
| 시간 도전 | 사용 불가 | 선택 | 선택 |
| 문장 | 해설을 두 문장 이내로 줄이고 "더 알아보기"로 나머지 표시 | 기본 | 기본 |
| 점수·별 | 같은 기준 | 같은 기준 | 같은 기준 + 도전 과제 |

- 차근차근 모드에서 줄인 사례는 연습실에서 언제든 풀 수 있다. 진행·해금 조건은 모든 모드가 같다.
- 모드는 설정에서 언제든 바꿀 수 있고, 진행 중인 사례 상태는 유지된다.
- 보호자와 함께 하는 어린이, 처음 스마트폰 게임을 해 보는 어르신에게는 차근차근 모드를 첫 실행 화면에서 추천 문구 없이 같은 크기로 보여 준다(어느 세대도 '쉬운 모드 대상'으로 낙인찍지 않기 위함).
