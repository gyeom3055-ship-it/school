# DIGITAL GUARD 플레이 가이드 (게임 밖 설명)

[← 목차로](README.md)

게임 화면에는 **규칙(오늘의 조건) · 사건 · 결과**만 나옵니다. 튜토리얼, 조작 안내, 모드·난이도 설명은 게임 안에 넣지 않고 이 문서와 발표 자료의 "플레이 가이드" 슬라이드로만 전달합니다 ([15.10](11-modes-and-ui.md#1510-게임으로서의-정리-v04)).

## 한 판의 흐름

1. **메인**에서 일반 모드나 경쟁 모드를 고릅니다.
2. **난이도**(쉬움 · 보통 · 어려움 · 전문가)를 고릅니다.
3. **브리핑**에서 오늘의 조건을 봅니다.
4. **창구**에 상대가 와서 문자·메일·파일 요청을 내밉니다. 서류를 살피고 판정합니다.
5. 모든 사건을 처리하면 **근무 결과**에서 정답과 해설이 한꺼번에 공개됩니다.

## 조작

| 도구 | 하는 일 |
|---|---|
| 대조 | 정보 두 개를 차례로 누르면 **일치 · 불일치**가 표시됩니다. 같은 종류끼리만 비교할 수 있습니다 (예: 링크 주소 ↔ 공식 주소, 보낸 번호 ↔ 저장된 연락처). 다른 서류 탭의 정보와도 비교할 수 있습니다 |
| 표시 | 의심스러운 곳에 **깃발**을 꽂거나 뺍니다 |
| 조회 | 센터가 가진 자료(등록 기기 목록, 교직원 연락처 등)를 꺼냅니다. 몇 번을 해도 감점이 없습니다 |
| 규칙 | 오늘의 조건과 규칙집을 다시 봅니다 |
| 첨부 파일 | 누르면 **파일 정보**가 열립니다: 전체 파일 이름, 마지막 확장자(진짜 종류), 압축 안에 든 파일 |
| 근거 트레이 | 대조로 만든 단서와 깃발이 모입니다. ✕로 단서를 지울 수 있습니다 |
| 판정 | **승인**은 바로 처리됩니다. **거부**는 신고 여부를, **추가 확인**은 근거와 확인 경로를 고른 뒤 보냅니다. 다시 묻는 확인 창은 없습니다 |
| 일시정지 | 왼쪽 위 버튼: 계속하기 · 소리 · 분위기 · 글자 크기 · 처음 화면으로 나가기 |

## 규칙

- 판정이 맞았는지는 **근무가 끝난 뒤 한꺼번에** 공개됩니다. 처리할 때는 도장만 찍힙니다.
- 남은 사건 수는 표시되지 않습니다.
- 위험한 요청을 승인하면 **보안 사고**로 그 자리에서 근무가 끝납니다.
- 끝까지 해도 처리 성공률(정답 + 허용되는 다른 답)이 **60% 미만**이면 **점검 미달**입니다.
- 보안 사고나 점검 미달이면 결과를 보고 **그 난이도를 처음부터** 다시 합니다.
- 낯설다고 모두 위험한 것은 아닙니다. 정상 요청을 막으면 편의 게이지가 떨어지고 감점됩니다.

## 점수

| 항목 | 점수 |
|---|---|
| 판정 정답 | 100 (허용되는 다른 답은 일부) |
| 위험 요소에 깃발 | 필수 20 · 보조 10, 엉뚱한 깃발은 -5 |
| 핵심 대조 | 20 |
| 근거 · 확인 경로 | 각 최대 30 |
| 신고 판단 | 10 |
| 연속 정답 | 최대 40 |
| 시간 보너스 (경쟁 모드) | 맞힌 사건의 남은 초 × 1 |

별은 통과했을 때만 받습니다 (정확도·위험 탐지에 따라 1~3개).

## 모드

| | 일반 모드 | 경쟁 모드 |
|---|---|---|
| 시간 | 제한 없음 | 사건마다 쉬움 60 · 보통 50 · 어려움 45 · 전문가 40초. 10초 남으면 빨간색 |
| 시간 초과 | — | "시간 초과" 도장, 그 사건은 놓친 것으로 처리 |
| 나가기 | 진행이 저장되어 **이어서 하기** 가능 | 이번 도전 기록이 사라짐 |
| 랭킹 | — | 결과에 점수와 순위 표시. 보안 사고 판은 랭킹에 오르지 않음 |

## 난이도

화면과 조작은 모든 난이도에서 같고, 들어오는 사건만 어려워집니다. 앞 난이도를 통과하면(어느 모드든) 다음 난이도가 열립니다.

| 난이도 | 들어오는 사건 | 필요한 판단 |
|---|---|---|
| 쉬움 | 문자 · 메시지 | 서류 2~3장 대조, 승인·거부 |
| 보통 | 메일 · 첨부파일 · 로그인 알림 | 파일 정보(확장자), 자료 조회 |
| 어려움 | 가족 · 지인 사칭 | 추가 확인, 근거, 확인 경로 |
| 전문가 | 2단계 사건 · 재촉하는 메시지 | 모든 도구, 확인 결과를 보고 다시 판정 |

## 이름과 기록

- 플레이어 이름은 미리 만든 조합(예: "꼼꼼한 수달 21")에서 뽑습니다. 실명·나이·연락처는 묻지 않습니다.
- 진행과 랭킹은 기기 안에만 저장됩니다. 여러 사람이 함께 보는 서버 랭킹은 2단계(다음 학기) 계획입니다.
- 설정 → 기록 초기화로 모두 지울 수 있습니다.

## 시제품에 대해

- [HTML 시제품](prototype/README.md)은 Unity로 만들기 전에 화면과 흐름을 확인하는 용도입니다.
- 게임 속 인물·기관·번호·주소는 모두 가상이며, 주소는 `.example` 예약 도메인만 씁니다. 링크와 파일은 실제로 열리지 않습니다.
