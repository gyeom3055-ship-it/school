## 2. 꼭 지킬 원칙 (지금까지 사용자가 정한 것)

1. **호칭은 "플레이어".** "심사관" 같은 직함은 쓰지 않는다. 게임 속 직업은 "창구 직원".
2. **교육용이 아니라 게임이다.** 소재가 사칭·피싱일 뿐, 발표·화면에서 교육 효과를 앞세우지 않는다. 교육 목표(기획서 2장)는 사건 설계용 내부 기준으로만 남긴다.
3. **인게임에 튜토리얼·안내 문구를 넣지 않는다.** 화면에는 규칙(오늘의 조건)·사건·결과만. 설명은 `play-guide.md`와 발표 자료의 "플레이 가이드" 슬라이드에 둔다.
4. **판정 흐름 (v0.3부터):** 다시 확인 창 없음 · 남은 사건 수 표시 없음 · 정답은 판정 직후가 아니라 **근무가 끝난 뒤 한꺼번에** 공개.
5. **실패 규칙:** 위험한 요청 승인 = 보안 사고(즉시 종료), 처리 성공률 60% 미만 = 점검 미달 → 결과를 보고 그 난이도를 **처음부터** 다시.
6. **정답을 흘리지 않는다.** 서류 안에 "안전해요" 같은 판정 대신 문장 금지. 낯설지만 정상인 사건(사진 압축 파일, 공용 태블릿 로그인 등)을 30~40% 섞는다.
7. **가상 데이터만.** 실존 기관·인물 없음, 주소는 `.example` 도메인, 실명·나이 입력 없음, 광고·결제·추적 없음.
8. **발표 자료 스타일:** 16:9, 도트(픽셀) 스타일, 다크 배경, Galmuri 글꼴(제목) + 맑은 고딕(본문), 모든 게임 화면은 "HTML 시제품 캡처(Unity 구현 전)"로 표시, 슬라이드 노트 포함.
9. 사용자는 문헌정보학과 + 컴퓨터공학 복수전공. 마케팅 용어 사용 가능. 도서관 관련 기획에는 그 배경을 참고(이 게임에는 강조하지 않음).

## 5. 만드는 법

**시제품**
```bash
npm install galmuri && pip install fonttools brotli
python3 docs/digital-guard/prototype/src/build.py node_modules/galmuri/dist
# → docs/digital-guard/prototype/digital-guard-pixel.html
```

**시제품 화면 캡처 (PPT용)**
```bash
cd docs/digital-guard/presentation/src
npm install playwright   # Chromium 필요
node capture.js "$PWD/shots4" "/절대경로/docs/digital-guard/prototype/digital-guard-pixel.html"
# 메인·난이도·인게임·일시정지·결과·경쟁·랭킹·밝게 모드 화면을 찍고, 콘솔에 errors: [] 이면 정상
```

**기획서 합본 (Word · PDF)** — md 파일을 고친 뒤 다시 만들 때
```bash
cd docs/digital-guard/combined/src
python3 build.py                                   # → book_fixed.docx (pandoc, lxml 필요)
soffice --headless --convert-to pdf book_fixed.docx # → book_fixed.pdf (LibreOffice)
python3 pages.py && python3 build.py               # 목차 쪽수 다시 계산 후 한 번 더
soffice --headless --convert-to pdf book_fixed.docx
# 결과를 ../DataPlease_기획서_합본.docx / .pdf 로 복사
```
- 합치는 순서: 개요(README) → 1~14장 → 15장 → 부록 → 플레이 가이드 → 인계 노트. 문서 사이 링크는 글자만 남긴다.
- Word에서 열면 목차 업데이트를 물어본다. "예"를 누르면 Word 기준 쪽수로 다시 맞춰진다.

**발표 자료**
```bash
cd docs/digital-guard/presentation/src
npm install
node build_deck.js ../DataPlease_중간설계발표.pptx
# 글꼴 Galmuri가 설치된 PC에서 열어야 제목 줄바꿈이 맞음
```
- 화면 슬라이드의 빨간 번호는 `capture.js`가 남기는 `boxes.json`의 y 좌표(374×832 기준)로 위치를 정한다. 시제품 화면이 바뀌면 다시 캡처하고 `at:` 값을 고친다.
- 렌더 확인: LibreOffice로 PDF 변환 → 이미지로 넘겨 겹침·넘침을 눈으로 확인했다.
