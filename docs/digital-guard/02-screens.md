# 4장. 핵심 화면과 화면별 구성 요소

[← 목차로](README.md)

> 모든 화면은 **세로(Portrait) 1080×1920 기준 해상도**로 설계하고, Safe Area 안에 배치한다. 와이어프레임은 테마와 무관한 *구조*만 나타내며, 실제 모양은 [8장 테마 가이드](05-visual-themes.md)를 따른다. (와이어프레임의 한글 폭 때문에 선 정렬이 조금 어긋나 보일 수 있다.)

## S01. 첫 실행

```
┌────────────────────────────┐
│        Data, Please.        │
│   누리 디지털 안전 센터에    │
│     오신 것을 환영해요!      │
│                            │
│  플레이어 이름은?           │
│  ┌──────────────────────┐  │
│  │ 반짝이는 부엉이 07  🔄 │  │  ← 🔄 탭: 프리셋 조합 다시 뽑기
│  └──────────────────────┘  │
│                            │
│  화면 스타일                 │
│  [ 도트 ✓ ]  [ 모던 ]        │  ← 미리보기 썸네일 포함
│                            │
│  글자 크기 가 [가] 가 가 가   │  ← 5단계, 즉시 미리보기
│                            │
│  플레이 모드                 │
│  [차근차근] [표준 ✓] [도전]   │  ← 언제든 설정에서 변경
│                            │
│      [ 출근하기 ▶ ]          │
└────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| 닉네임 | 형용사 30종 × 동물 30종 × 두 자리 숫자 조합. **자유 입력 불가**(실명 입력 방지). 🔄로 재추첨 |
| 화면 스타일 | 도트(기본)/모던 썸네일을 탭하면 이 화면 자체가 해당 테마로 즉시 바뀌어 미리보기 |
| 글자 크기 | 100% / 115% / 130% / 150% / 175%. 이후 설정에서 언제든 변경 |
| 플레이 모드 | 차근차근 / 표준 / 도전. 나이를 묻지 않고 플레이어가 고른다 ([7.8](04-levels-and-scoring.md#78-플레이-모드-전연령-지원)) |
| 출근하기 | 저장 데이터 생성 → 튜토리얼(Day 0) 시작 |

## S03. 오늘의 소식 · 아침 브리핑

**① 오늘의 소식** (2~3문장 카드, 건너뛰기 가능)
> 📰 *누리 소식* — "요즘 '계정이 정지된다'는 메일이 돌고 있대요. 진짜 공지는 누리배움터 공식 주소에서만 와요."

**② 새 규칙 카드** (새 규칙이 있는 날만)

```
┌────────────────────────────┐
│ 새 규칙  R-LINK-01  🔗       │
│ 링크 주소는 공식 도메인       │
│ 목록과 맞춰 봐요.            │
│                            │
│ 💡 도메인이란?               │
│ 인터넷 주소에서 '누구의 집'   │
│ 인지 알려 주는 이름이에요.    │
│                            │
│ ✔ 좋은 예                   │
│  https://baeumteo.example/  │
│ ✖ 헷갈리는 예                │
│  https://baeumteo.login-    │
│   check.example/            │
│  → 진짜 주인은 끝부분         │
│    'login-check.example'    │
│                            │
│ [ 예시 문제 풀어 보기 ▶ ]     │
└────────────────────────────┘
```

**③ 미니 연습** — 정답이 바로 공개되는 1~2문제. 점수에 반영하지 않는다. 틀리면 도트가 같은 원리를 다른 예로 한 번 더 보여 준다.

| 요소 | 동작 |
|---|---|
| 용어 말풍선(💡) | 용어가 처음 등장하면 자동 표시. 이후엔 밑줄 표시된 용어를 탭하면 다시 볼 수 있음. 보안 사전에 자동 등록 |
| 규칙 카드 | 브리핑 후 규칙집(S06)에 "NEW" 표시와 함께 추가됨 |
| 오늘의 조건 지정 | 브리핑을 마치면 "이 규칙을 오늘의 조건으로 붙여 둘게요" 연출과 함께 규칙 카드가 줄어들어 검토 데스크 맨 위 띠(S04 ⓪)로 이동한다. 복습 Day에는 집중할 점 카드 한 장으로 대신한다 |

## S04. 검토 데스크 (메인 플레이 화면)

```
┌────────────────────────────┐
│ ⏸  Day 5 · 중급       ⏳--  │ ← 상단 바: 일시정지, Day·등급, (선택)타이머. 남은 사건 수는 표시하지 않음
│ 📌 오늘의 조건: 링크는 끝부분 ▸│ ← ⓪ 오늘의 조건 띠 (탭: 규칙 카드)
├────────────────────────────┤
│ ┌────────────────────────┐ │
│ │ 📨 요청 카드              │ │ ← ① 요청 요약
│ │ 하은솔 님 문의:           │ │
│ │ "이 메일 링크로 로그인     │ │
│ │  해도 될까요?"           │ │
│ └────────────────────────┘ │
│                            │
│ ┌────────────────────────┐ │ ← ② 문서 뷰어 (스크롤·확대)
│ │ ✉ 받은 메일              │ │
│ │ 보낸 사람:               │ │
│ │ notice@baeumteo-        │ │
│ │  security.example  🚩   │ │ ← 깃발 꽂힌 필드
│ │ 제목: [긴급] 계정 정지…   │ │
│ │ 링크: http://baeumteo.  │ │
│ │  login-check.example/…  │ │
│ └────────────────────────┘ │
│ [✉메일][📋도메인][📢공지][👤내 기록]│ ← ③ 문서 트레이 (탭 전환)
├────────────────────────────┤
│ 🔍대조  🚩표시  📖규칙  📂조회 │ ← ④ 도구 바
│ 단서: [⚠도메인 불일치] [⚠공지 없음]│ ← ⑤ 근거 트레이 (가로 스크롤)
├────────────────────────────┤
│ [✔ 승인] [✖ 거부] [? 추가 확인]│ ← ⑥ 판정 패널
└────────────────────────────┘
```

### 구성 요소

| # | 요소 | 설명 | 상호작용 |
|---|---|---|---|
| ⓪ | 오늘의 조건 띠 | 아침 브리핑의 규칙 카드를 한 줄로 요약해 데스크 맨 위에 고정. 복습 Day에는 그날 집중할 점 한 가지 | 탭 → 규칙 카드 전체(좋은 예·나쁜 예)를 바텀 시트로 표시. 차근차근 모드에서는 한 줄 대신 두 줄로 크게 |
| ① | 요청 카드 | 누가, 무엇을, 왜 요청하는지 1~3문장 요약 | 탭하면 원문 요청서가 문서 뷰어에 열림 |
| ② | 문서 뷰어 | 현재 선택된 문서를 카드 형태로 표시. 각 정보는 *필드* 단위로 구분 | 세로 스크롤, 핀치 확대(100~250%), 더블탭 확대, ⊕⊖ 버튼(드래그 없는 대체) |
| ③ | 문서 트레이 | 이 사례에서 볼 수 있는 문서 탭(2~5개) + 항상 맨 끝에 있는 **👤 내 기록** 탭(요청자의 주문 내역·저장된 연락처·신청 내역·내가 요청한 파일). 새로 추가된 문서엔 ● 표시 | 탭으로 전환. 길게 누르거나 "⇅ 비교" 버튼으로 비교 모드(S05) |
| ④ | 도구 바 | 해금된 도구만 표시. 각 아이콘 아래에 항상 텍스트 라벨 | 아래 '도구 동작' 표 참고 |
| ⑤ | 근거 트레이 | 생성된 단서 칩과 깃발 목록 | 칩 탭: 해당 필드로 이동·하이라이트. 칩 길게 누르기 또는 ✕: 삭제 |
| ⑥ | 판정 패널 | 사례에 허용된 판정만 표시(초급은 승인·거부 2개) | 승인은 탭 즉시 처리, 거부·추가 확인은 처리 시트(S07). 판정 확인 단계 없음. 패널은 화면 하단 고정, 높이 최소 64dp |

### 도구 동작

| 도구 | 해금 | 기본 조작 (탭만으로 가능) | 보조 조작 | 결과 |
|---|---|---|---|---|
| 🔍 **대조** | Day 0 | 대조 모드 켜기 → 필드 A 탭 → (다른 문서로 전환) → 필드 B 탭 | 필드 A를 길게 눌러 끌어다 필드 B에 놓기 | 두 필드의 `compareKey`가 같은 종류일 때 *일치(✓)* 또는 *불일치(⚠)* 단서 칩 생성. 비교할 수 없는 조합이면 "이 두 정보는 서로 비교하기 어려워요" 안내(감점 없음) |
| 🚩 **표시** | Day 2 | 표시 모드 켜기 → 의심 필드 탭 | 필드를 길게 눌러 나오는 메뉴에서 "의심 표시" | 필드에 깃발. 다시 탭하면 해제. 정답 공개 전까지는 맞았는지 알려 주지 않음 |
| 📖 **규칙** | Day 0 | 탭 → 규칙집 시트(S06) | — | 현재 사례 진행 상태는 그대로 유지 |
| 📂 **자료 조회** | Day 7 (기기 기록), Day 9 (공식 연락처), Day 13 (관리자 명부) | 탭 → 조회 가능한 자료 목록에서 선택 | — | 해당 자료가 문서 트레이에 추가(● 표시). 조회는 무제한·무감점. *추가 확인 판정*과는 다르다(아래 주의 참고) |
| 📎 **파일 정보 보기** | Day 6 | 첨부 파일 필드 탭 → "파일 정보 보기" | — | 파일은 **열리지 않는다**. 전체 파일 이름(확장자 강조), 파일 종류, 크기, 압축 파일이면 내용 목록을 시트로 표시. 확장자를 탭하면 확장자 도감 항목이 열린다 |

> **주의 — '자료 조회'와 '추가 확인 판정'의 구분** (v0.1의 같은 이름 문제를 고침, [G2](01-overview.md#33-게임플레이-단계-점검-v02))
> - *자료 조회(📂 도구)*: 플레이어가 센터 안에서 이미 가진 자료(등록 기기 목록, 공식 연락처 등)를 꺼내 보는 행동. 판정 전 자유롭게 사용.
> - *추가 확인 판정(? 버튼)*: 센터 자료만으로는 판단할 수 없어 **요청자나 담당자에게 공식 경로로 확인을 요청하는 판정**. 사례를 일단 보류하는 선택이다.

### 필드 상태 표시 (색 + 아이콘 + 텍스트 병행)

| 상태 | 표시 |
|---|---|
| 기본 | 테두리 없음 |
| 대조 중 선택됨 | 굵은 테두리 + "①선택됨" 라벨 |
| 일치 확인됨 | ✓ 아이콘 + "일치" 작은 라벨 |
| 불일치 발견 | ⚠ 아이콘 + "불일치" 라벨 + 빗금 배경 패턴 |
| 의심 표시 | 🚩 아이콘 + "의심" 라벨 |
| 해설 시 위험 위치 | ❗ 아이콘 + "위험 요소" 라벨 + 굵은 점선 테두리 |

## S05. 문서 뷰어 · 비교 모드

세로 화면에서는 **위·아래 분할**로 두 문서를 동시에 띄운다(태블릿·가로폭 넓은 기기는 좌우 분할).

```
┌────────────────────────────┐
│ 비교 모드          [✕ 닫기] │
├────────────────────────────┤
│ ▼ 위: [✉ 받은 메일 ▾]       │ ← 문서 선택 드롭다운
│  보낸 사람: notice@baeumteo-│
│   security.example         │
├──────── ═══ ───────────────┤ ← 경계선: 드래그로 비율 조정 / 탭하면 50:50 ↔ 70:30 전환
│ ▲ 아래: [📋 도메인 목록 ▾]   │
│  공식 발신 주소:              │
│   notice@baeumteo.example  │
├────────────────────────────┤
│ 🔍대조 🚩표시   단서: [⚠…]   │
└────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| 위/아래 문서 선택 | 같은 문서를 양쪽에 고를 수 없음 |

## S07. 처리 시트 (거부·추가 확인일 때만)

> **v0.3:** "○○로 판정할까요? [다시 볼래요] [확정]" 같은 **판정 확인 단계는 없앴다.** 판정 버튼을 누르면 바로 처리된다. 다만 거부와 추가 확인은 *처리에 필요한 정보*(신고 여부, 근거, 확인 경로)를 받아야 하므로 입력 시트를 띄운다. 이 시트는 확인 질문이 아니라 입력 화면이다.

| 판정 | 버튼을 누른 뒤 |
|---|---|
| 승인 | 바로 처리 → 처리 완료 도장(S08) |
| 거부 | 처리 시트: (고급 이상) 근거 선택 + **신고할까요?** [안내만 하기]/[신고하기] → [거부하기] |
| 추가 확인 | 처리 시트: (고급 이상) 근거 선택 + **누구에게, 어떤 경로로 확인할까요?** → [확인 요청 보내기] |

```
┌────────────────────────────┐
│ 거부 처리                  ✕ │
│ 근거를 모두 골라요 (고급 이상) │
│  ☐ 공개 범위가 '링크가 있는    │
│     모든 사람'이다            │
│  ☐ 파일에 보호자 연락처가 있다  │
│  ☐ 편집 권한이 열려 있다       │
│ 신고도 할까요?                │
│  ☐ 안내만 하기  ☑ 신고하기     │
│        [ 거부하기 ]           │
└────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| ✕ | 시트를 닫고 데스크로 돌아간다(판정은 아직 처리되지 않음) |
| 근거 보기 | 정답 근거 1~3개 + 그럴듯한 오답 근거 1~3개. 보기 순서는 매번 섞음 |
| 확인 경로 | 경로를 틀려도 그 자리에서 알려 주지 않는다. 2단계 사례에서는 고른 경로에 따라 **다른 답이 도착**한다(예: 메시지를 보낸 번호로 물으면 "응, 선생님 맞아"라는 답장) |
| 중복 입력 방지 | 처리 버튼 탭 즉시 비활성화. 같은 사건에 대한 두 번째 입력은 무시 ([12장](08-save-and-errors.md) 참고) |

## S08. 처리 완료 도장

> **v0.3:** 사건을 처리한 직후에는 **정답·오답을 보여 주지 않는다.** 정답과 해설은 근무가 끝난 뒤 근무 결과(S09)에서 한꺼번에 공개한다. 판정마다 정답을 알려 주지 않기 때문에, 플레이어는 규칙과 자료에 기대어 스스로 판단하게 된다.

```
┌────────────────────────────┐
│         ┌──────┐            │
│         │ 거부 │  ← 내가 고른 판정 도장 (색은 중립)
│         └──────┘            │
│   거부하고 신고했어요.         │
│      [ 다음 요청 ▶ ]          │
└────────────────────────────┘
```

| 상황 | 표시 |
|---|---|
| 승인·거부 | 고른 판정 도장 + "승인했어요" / "거부하고 신고했어요" / "거부하고 안내했어요" |
| 추가 확인 (1단계 사건) | "확인 요청을 보냈어요. 답은 근무가 끝나면 함께 알려 드려요." 확인 결과 카드는 근무 결과에서 보여 준다 |
| 추가 확인 (2단계 사건) | 도장 없이 바로 답 문서가 트레이에 도착하고 2단계 판정을 이어 간다 |
| 마지막 사건 | 버튼이 [근무 마치기 ▶]로 바뀐다 |
| 보안 사고 | 위험도 '높음' 사건을 승인하면 도장 대신 바로 근무 결과(실패)로 간다 |

- 남은 사건 수, 정답 여부, 점수는 이 화면에 표시하지 않는다.

## S09. 근무 결과 (일일 리포트)

근무를 끝까지 마쳤거나 **실패**했을 때 표시한다. 정답과 해설은 여기서 처음 공개된다.

```
┌────────────────────────────┐         ┌────────────────────────────┐
│ Day 5 근무 완료!    ★★☆      │         │   ┌──────────┐              │
├────────────────────────────┤         │   │ 보안 사고 │               │
│ 판정 정확도      83%         │         │   └──────────┘              │
│ 위험 탐지율      90% (9/10)  │         │ 위험한 요청이 승인됐어요      │
│ 과잉 차단 0건 · 위험 승인 1건  │         │ 센터가 막아서 피해는 없었어요. │
│ 신고 판단 3/3 · 점수 820      │         │ 무엇을 놓쳤는지 보고          │
├────────────────────────────┤         │ 처음부터 다시 해요.           │
│ 안전 ■■■■■■■□□□ 편의 ■■■■■■■■■■│         ├────────────────────────────┤
├────────────────────────────┤         │ (지표 · 게이지)               │
│ 사건별 판정과 해설            │         │ 사건별 판정과 해설            │
│ ▸ 택배 주소 확인 문자  [맞음]  │         │ ▾ 택배 주소 확인 문자 [다시 볼 곳]│
│   내 판정 거부 · 정답 거부     │         │   내 판정 승인 · 정답 거부     │
│ ▸ 추석 사진 압축 파일  [맞음]  │         │   위험 요소 · 해설 · 다시 볼 곳 │
│ ▸ 손녀라는 새 번호 [더 좋은 답]│         │                            │
│ [ 처음부터 다시 하기 ] [ 다음 Day ]│      │ [ 처음부터 다시 하기 ▶ ]       │
└────────────────────────────┘         └────────────────────────────┘
        근무 완료                                   실패
```

| 요소 | 동작 |
|---|---|
| 지표·게이지 | 판정 정확도, 위험 탐지율, 과잉 차단, 위험 승인, 신고 판단, 점수, 안전·편의 게이지 |
| 사건별 판정과 해설 | 사건을 탭하면 펼쳐진다: 내 판정 / 정답, 위험 요소(찾음·못 찾음), 올바른 근거, 확인 경로 평가, 확인 결과 카드, **다시 볼 곳**(v0.2의 오답 힌트), 해설, 실천 팁, 후일담 |
| 실패 화면 | 보안 사고면 사고가 난 사건이 펼쳐진 채로 열린다. 기준 미달이면 처리 성공률과 기준을 보여 준다 |
| 처음부터 다시 하기 | 실패하면 이 버튼만 있다. 그 Day의 **첫 사건부터** 다시 시작한다(Day 시작 시점 저장으로 되돌림) |
| 다음 Day | 근무 완료일 때만 표시 |
| 시민 후일담 | 사건별 해설 안에 표시 (예: 과잉 차단 시 "할머니가 손주들 사진을 못 봤대요") |
