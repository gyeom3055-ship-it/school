# 발표 자료

[← 목차로](../README.md)

| 파일 | 내용 |
|---|---|
| `DIGITAL_GUARD_기획발표.pptx` | 게임 기획 발표 (16:9, 9장, 도트 스타일, 슬라이드 노트 포함, v0.3 기준) |
| `fonts/` | 제목·도트 글꼴 Galmuri14 / Galmuri11 / Galmuri11-Bold (SIL OFL 1.1, [`OFL-Galmuri.md`](fonts/OFL-Galmuri.md)). 용량을 줄이려고 영문·기호·KS X 1001 한글 2,350자만 남긴 부분 글꼴이다. 모든 글자가 필요하면 원본 Galmuri 배포본을 설치한다 |

## 글꼴 안내

- 제목과 도트 장식 글자는 **Galmuri** 글꼴을 쓴다. 본문은 기본 글꼴인 "맑은 고딕"이다.
- 발표할 PC에 `fonts/` 안의 TTF 세 개를 먼저 설치한다. 설치하지 않으면 제목이 다른 글꼴로 바뀌어 보이고, 줄바꿈 위치가 달라질 수 있다.
- 줄인 글꼴에 없는 글자(예: `✓`, 드문 한글)는 다른 글꼴로 대신 보인다.
- 모든 글자는 텍스트 상자라서 PowerPoint에서 바로 고칠 수 있다. 도트 일러스트(키아트·아이콘·화면 목업)는 이미지다.

## 주의

- 게임 화면은 모두 **예상 UI/목업**이며, Unity 구현물이 아니다. 화면 목업은 HTML 시제품(`../prototype/`)과 같은 v0.3 흐름을 따른다.
- 이름 "DIGITAL GUARD"는 아직 가칭이다. 후보는 [부록 D](../10-appendix.md)에 있다.
