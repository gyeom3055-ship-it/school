# 15장. 모드·난이도·화면 흐름 (v0.4 회의 반영)

[← 목차로](README.md)

팀 회의 메모(손그림)를 구체화한 장입니다. 이 장의 내용이 앞 장과 다르면 **이 장이 우선**합니다. 앞 장에서 바뀌는 곳은 [15.9](#159-앞-장에서-바뀌는-곳)에 모았습니다.

## 15.1 회의 메모 정리

| 메모 | 이렇게 구체화함 |
|---|---|
| 분위기: 어둡게? 밝게? | 두 분위기를 모두 만들고 설정에서 고른다. 기본은 **어둡게(밤 근무)**, 선택하면 **밝게(낮 근무)**. 발표에서 팀 의견을 받아 기본값을 확정한다 ([15.7](#157-분위기-어둡게--밝게)) |
| 모든 것 한 명 (유저 역할) | 창구는 **플레이어 한 명**이 맡는다. 들어오는 모든 요청을 혼자 보고 판정한다. 동료·상사 역할 전환은 없다 |
| 난이도: 화면은 똑같이(Play), 문자 → … | **화면과 조작은 모든 난이도에서 같다.** 난이도가 오를수록 들어오는 사건만 바뀐다: 문자 → 메일·첨부파일 → 가족 사칭·추가 확인 → 2단계 사건 ([15.4](#154-난이도-4단계)) |
| 1. 메인 화면 (세로 고정) | 위쪽 **사운드**(왼쪽)·**설정**(오른쪽), 가운데 **일반 모드 / 경쟁 모드**, 아래 **랭킹** |
| 2. 난이도 선택 | **쉬움 · 보통 · 어려움 · 전문가**. 앞 난이도를 통과해야 다음 난이도가 열린다 |
| 3. 인게임 화면 (Papers, Please) | 창구 구도: 위쪽에 **배경(창밖 도시)** 과 **상대방**, 상대가 보낸 **문자·메일 내용**이 말풍선으로 나온다. 아래는 서류·도구·판정 버튼 ([15.5](#155-인게임-화면-창구-구도)) |
| 인게임은 4장 정도로 나눠 설명 | 발표 자료에서 인게임을 ① 화면 구성 ② 단서 찾기 ③ 판정하기 ④ 일시정지·결과로 나눠 설명 |
| 설정 누르면 → 나가기 / 일시정지 | 인게임 왼쪽 위 **일시정지(⏸)** 버튼 → 계속하기 · 소리 · 분위기 · 글자 크기 · 나가기 ([15.6](#156-일시정지와-설정)) |

## 15.2 화면 흐름

```
메인 ─┬─ 일반 모드 ─┐
      ├─ 경쟁 모드 ─┴→ 난이도 선택 → 브리핑 → 인게임(사건 반복) → 근무 결과 ─┬→ 다음 난이도 / 다시 하기
      ├─ 랭킹                                    ↕                          └→ (경쟁) 랭킹
      └─ 설정                               일시정지 → 나가기 → 메인
```

| 화면 | 구성 | 비고 |
|---|---|---|
| 메인 | 사운드 · 설정 / 로고 · 보안관과 조수 도트 / 일반 모드 · 경쟁 모드 · 랭킹 / 플레이어 이름(뽑기) | 세로 고정. 일반 모드 진행이 남아 있으면 **이어서 하기** 버튼 |
| 난이도 선택 | 처음으로 · 모드 표시 / 4단계 카드(이름, 설명, ■□ 단계, 사건 수, 경쟁 모드면 사건당 시간·내 최고 점수) | 잠긴 카드에 "○○ 통과 시 열림" |
| 브리핑 | 모드·난이도·사건 수 / 오늘의 소식 / 오늘의 조건 카드 / 근무 수칙 | 경쟁 모드면 제한 시간 안내 추가 |
| 인게임 | 상단 바(⏸ · 소리 · 난이도·모드 · 경쟁 모드 타이머) / 오늘의 조건 띠 / 창구 장면 / 서류 탭 / 근거 트레이 / 도구 4개 / 판정 버튼 | [15.5](#155-인게임-화면-창구-구도) |
| 처리 시트 · 처리 완료 | v0.3과 같음 (거부·추가 확인만 시트, 도장만 찍고 정답 비공개) | 경쟁 모드 시간 초과면 "시간 초과" 도장 |
| 근무 결과 | 별점 / (경쟁) 점수·랭킹 순위·시간 보너스 / 지표 / 게이지 / 사건별 정답·해설 | 일반: 다음 난이도 · 다시 하기, 경쟁: 다시 도전 · 랭킹 |
| 랭킹 | 난이도 탭 4개 / 상위 10명(순위, 이름, 정확도, 날짜, 점수) / 방금 기록 강조 | 1단계는 기기 안 기록 ([15.3](#153-일반-모드와-경쟁-모드)) |

## 15.3 일반 모드와 경쟁 모드

| 구분 | 일반 모드 | 경쟁 모드 |
|---|---|---|
| 목적 | 차근차근 읽고 판단 | 같은 사건을 빠르고 정확하게 |
| 시간 | 제한 없음 | **사건마다 제한 시간** (쉬움 60초 · 보통 50초 · 어려움 45초 · 전문가 40초). 일시정지하면 멈춤 |
| 시간 초과 | — | 그 사건은 "시간 초과"로 처리(오답과 같음)하고 다음 사건 |
| 점수 | 판정·위험 표시·근거·경로·신고·연속 정답 (7.2와 같음) | 일반 점수 + **시간 보너스**(맞힌 사건의 남은 초 × 1점) |
| 정답 공개 | 근무가 끝난 뒤 한꺼번에 | 같음 |
| 실패 | 보안 사고 즉시 종료, 처리 성공률 60% 미만이면 점검 미달 → 처음부터 | 같음. 보안 사고 기록은 **랭킹에 올리지 않음** |
| 이어 하기 | 나갔다 와도 이어서 하기 | 나가면 이번 도전 기록이 사라짐(공정성) |
| 난이도 열기 | 둘 중 어느 모드로든 통과하면 다음 난이도가 열린다 | |

**랭킹 단계 계획**
- 1단계(이번 학기 시제품): 기기 안 상위 10개 기록. 이름은 미리 만든 조합(예: "꼼꼼한 수달 21")만 쓴다.
- 2단계(다음 학기): 과제 계획서의 서버(Spring Boot · MySQL)로 함께 보는 랭킹. 점수는 **서버가 판정 기록으로 다시 계산**해 조작을 막고, 계정은 이름·기기 식별자만 받는다(실명·나이·연락처 없음). 서버가 없어도 일반 모드는 오프라인으로 그대로 된다.

## 15.4 난이도 4단계

화면과 조작은 같고, 사건의 종류와 단서 수, 필요한 도구만 늘어난다.

| 난이도 | 들어오는 사건 | 필요한 판단 | 시제품 사건 | 열림 조건 |
|---|---|---|---|---|
| 쉬움 | 문자 · 메시지 한 통 | 서류 2~3장 대조, 승인·거부 | 택배 주소 문자, 추석 사진 압축 파일 | 처음부터 |
| 보통 | 메일 · 첨부파일 · 로그인 알림 | 파일 정보(확장자), 자료 조회 | + 견적서(.pdf .exe), 처음 보는 기기 로그인 | 쉬움 통과 |
| 어려움 | 가족·지인 사칭 | 추가 확인, 근거 고르기, 확인 경로 | 사진 압축 파일, 견적서, 로그인, 손녀라는 새 번호 | 보통 통과 |
| 전문가 | 2단계 사건, 재촉하는 메시지 | 모든 도구, 확인 결과를 보고 다시 판정 | 6건 전부 (선생님 사칭 2단계 포함) | 어려움 통과 |

본 게임에서는 [6장 레벨 구성](04-levels-and-scoring.md#6-레벨-구성)의 Day 사례를 이 네 단계로 묶어 배치한다. 난이도마다 **정상 요청(승인이 정답)을 30~40% 섞는** 원칙은 그대로다.

## 15.5 인게임 화면 (창구 구도)

Papers, Please의 "창구 너머 사람 + 책상 위 서류" 구도를 세로 화면에 맞췄다.

| 영역 | 내용 |
|---|---|
| 상단 바 | ⏸ 일시정지 · 🔈 소리 / 난이도 · 모드 · 상태 / (경쟁) 남은 시간, 10초 이하면 빨간색 |
| 오늘의 조건 띠 | 난이도별 핵심 규칙 한 줄. 누르면 규칙 카드 |
| 창구 장면 | 창밖 도시 배경(밤·낮) + 창구 앞 **상대방**(도트 흉상) + 상대가 보낸 **문자·메일 내용 말풍선** |
| 서류 탭 | 받은 문자/메일 · 공식 연락처 · 내 기록 · 파일 정보 · 조회한 자료 |
| 근거 트레이 | 대조로 만든 단서(일치·불일치)와 의심 깃발 |
| 도구 | 대조 · 표시 · 조회 · 규칙 |
| 판정 버튼 | 승인 · 거부 · (필요할 때) 추가 확인 |

## 15.6 일시정지와 설정

| 어디서 | 열리는 것 | 항목 |

| 인게임·브리핑·결과의 ⏸ | 일시정지 | 계속하기 / 소리 켜기·끄기 / 분위기 어둡게·밝게 / 글자 크기 5단계 / 문서 글꼴 / 처음 화면으로 나가기(한 번 더 확인) |

## 15.7 분위기: 어둡게 · 밝게

| | 어둡게 (밤 근무, 기본) | 밝게 (낮 근무) |
|---|---|---|
| 느낌 | 집중, 긴장감, 도트 네온 | 친근함, 가벼움, 오래 봐도 편함 |

| 잘 맞는 상황 | 경쟁 모드, 몰입 플레이 | 일반 모드, 밝은 곳·오래 하기 |
| 구현 | 같은 화면에 색 변수만 교체 (판정 로직·데이터 동일) | |

## 15.10 게임으로서의 정리 (v0.4)

Data, Please.는 **게임**이다. 생활 속 사칭·피싱은 *소재*이고, 재미의 중심은 단서를 대조해 가려내는 추리와 경쟁이다.

| 원칙 | 내용 |
|---|---|
| 호칭 | 게임 안팎에서 사용자를 **플레이어**라고 부른다. "심사관" 같은 직함은 쓰지 않는다 (게임 속 직업은 "창구 직원") |
| 인게임 문구 | 화면에는 **규칙(오늘의 조건)·사건·결과**만 둔다. 튜토리얼, 조작 안내, 모드·난이도 설명, 개인정보 안내, 제작 메모는 넣지 않는다 |
| 설명의 자리 | 빠진 설명은 [플레이 가이드](play-guide.md) 문서와 발표 자료의 **플레이 가이드** 슬라이드(게임 밖 설명)에 둔다 |
| 결과 화면 | 사건별 정답·위험 요소·해설·인물 반응은 보여 주되, "이렇게 해요" 같은 생활 수칙과 "다시 볼 곳" 힌트는 넣지 않는다 |
| 교육 목표(2장) | 사건을 설계할 때 쓰는 내부 기준으로만 남긴다. 화면·발표에서 교육 효과를 앞세우지 않는다 |

**시제품에서 뺀 문구 → 발표 자료 "플레이 가이드"로 옮김**

| 있던 곳 | 뺀 문구 |
|---|---|
| 화면 옆 안내 패널 | 시제품 소개, 도구 설명(대조·표시·조회·규칙), 가상 데이터 안내 |
| 메인 | 모드 버튼 아래 설명, 이름 안내("실명·나이는 묻지 않아요"), "HTML 시제품" 표시, 부제 |
| 난이도 선택 | 난이도별 긴 설명, "화면과 조작은 모든 난이도가 같아요" |
| 브리핑 | 좋은 예·주의 예, 용어 설명, 근무 수칙 카드 |
| 인게임 | 대조·깃발 모드 안내 문장, 빈 근거 트레이 안내, 조회 안내, 처리 완료 뒤 "답은 근무가 끝나면…" |
| 일시정지 | "잠깐 쉬어도 괜찮아요" 등 안내 |
| 결과 | "사건을 누르면…" 안내, 생활 수칙(이렇게 해요), 힌트(다시 볼 곳), 마무리 조언 말풍선 |
| 랭킹 | "이 기기의 기록만…" 안내, 예시 기록 행 |
